Las notas de GitHub Releases muestran imágenes en línea únicamente cuando sus URL son
accesibles. La plantilla utiliza URL de GitHub autenticables mientras el repositorio es
privado y que siguen siendo válidas cuando pasa a ser público.

Un MP4 adjunto a una versión puede aparecer solo como descarga. Para un tutorial con
reproductor y vista previa, súbelo a YouTube (también como no listado) y enlázalo desde
las notas de la versión con una miniatura enlazada.
